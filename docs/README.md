## Status

All 107 items of the original plan (`instructions.txt` at the repository root) are done, plus solo play (f108). Gaps that remain are listed where they matter:

- Spells: [about 38 percent](spell-automation.md) resolve automatically; the rest are cast and logged and the DM decides the effect.
- Public launch: the extracted handbook text must not be published; use SRD-only mode and re-import from SRD source files ([licensing.md](licensing.md)).
- A screen reader pass by a person is still a manual release step ([accessibility.md](accessibility.md)).
- Solo play limits: [solo-play.md](solo-play.md#limits-and-known-gaps).

## Conventions

- **Content versus play state.** Rules content is seeded and read-only; everything people create is play state.
- **Engine versus app.** `engine/` is pure and tested without a database; `lib/` talks to the database; `app/` is the interface.
- **One implementation of each rule.** Server actions, the computer players and the tests all go through the same code.
